### 🚀 Projetos em Destaque

#### 1. 🛒 [PuffsZone — Sistema de Gestão Comercial e PDV](https://puffszone.tech)
> **Projeto próprio em produção real na web**: [puffszone.tech](https://puffszone.tech) | **Código**: [github.com/davifeels/PuffsZone](https://github.com/davifeels/PuffsZone)
- Sistema web comercial completo com Ponto de Venda (PDV) ágil, controle de estoque, gestão de turnos de caixa, contas a pagar/receber e cupons de desconto.
- Backend em **Java 21 e Spring Boot 3** com Spring Security, autenticação stateless JWT, controle de acesso RBAC e auditoria.
- Persistência em **PostgreSQL 16** com versionamento contínuo de banco via **Flyway**.
- Frontend reativo em **React 19, TypeScript e Tailwind CSS**.
- Deploy real em **VPS Linux** conteinerizado com **Docker Compose**, proxy reverso **Nginx** e certificado SSL/HTTPS Let's Encrypt.

#### 2. 🛡️ DataProtection — Governança de Dados & LGPD
> **Projeto profissional desenvolvido no Instituto Nacional de Tecnologia da Informação (ITI)**
- Sistema de catalogação de operações de tratamento de dados pessoais conforme o Art. 37 da LGPD.
- Endpoints RESTful em Java e Spring Boot para governança, mapeamento de finalidades e agentes de tratamento.
- Controle de acesso granular por perfis (RBAC), autorização por setor, auditoria de ações críticas e exportação em Excel.
- **Stack:** `Java`, `Spring Boot`, `Angular`, `PostgreSQL`, `APIs REST`, `RBAC`.

#### 3. 📡 [RiskCore AI — Monitoramento de Reputação Digital](https://github.com/davifeels/riskcore-ai-frontend)
> **Código**: [github.com/davifeels/riskcore-ai-frontend](https://github.com/davifeels/riskcore-ai-frontend)
- Centro de comando para inteligência reputacional, detecção preditiva de crises e monitoramento de riscos com IA.
- Conexão e integração completa entre backend e interface web reativa.
- Persistência em **PostgreSQL** com **Prisma ORM** e camada de cache em **Redis** para alta performance.
- **Stack:** `Node.js`, `TypeScript`, `React`, `Next.js`, `PostgreSQL`, `Prisma ORM`, `Redis`.

#### 4. 🧠 [Nexus AI OS — Assistente com Memória Persistente](https://github.com/davifeels/nexus-ai-core)
> **Código**: [github.com/davifeels/nexus-ai-core](https://github.com/davifeels/nexus-ai-core)
